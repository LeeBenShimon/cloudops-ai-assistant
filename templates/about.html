Architecture

One document pipeline, one chat interface, one memory store.

This Flask app keeps the original RAG workflow intact: the report is chunked, embedded, searched with FAISS, and answered by Gemini. The added SQLite layer stores each session's messages so the assistant can stay coherent across follow-up prompts.
